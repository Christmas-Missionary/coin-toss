# Why?

I wanted to play around with assembly. This program can be assembled only on macOS (ARM64).

# How to build  
    whoami@hostname coin-toss % ./m.sh

# Usage
    whoami@hostname coin-toss % ./toss [optional number from 1 to 99]
  
  This program simulates flipping a coin however many times as inputted by you (From 1 to 99).
  Only the first two characters of the input string will be read.  
  Reading stops after the first character of invalid input and will instead generate one coin flip as if no input was given at all.  
  All other inputted arguments are ignored.
